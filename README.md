# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

**不通过行可发起退回重评**：发起时必填退回原因，系统生成退回单号（RT 开头）。重评提交时必须引用退回单号，服务端另生成一笔新审评行并将该退回单消单；未引用单号的普通交评不自动消单。顶栏「退回链」专页把每张退回单的原审评行（旧笔）与重评行（新笔）串在一起。观察员可查看退回链，但不能发起退回、不能提交重评。

这是制茶审评，不是菜谱，也不是饮食记录。

```bash
cd projects/13-tea-blend-cupping

```

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 对夏茶-C 发起退回（原因必填），得到退回单号 RT000001。
5. 引用该单号再递交香气 9、滋味 8、汤色 6，生成新审评行（7.9 通过），退回单消单；退回链专页同时出现旧笔（4.7 不通过）与新笔（7.9 通过）。
6. 不引用单号的普通交评不会消掉进行中的退回单；引用不存在或已消单的单号会被拒绝。
7. observer 能打开退回链，但发起退回、提交重评均返回 403。
