# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

不通过行可由审评员发起退回重评（必填退回原因），生成一张退回单。重评时在提交表单里引用退回单号，服务端生成新审评行并给该单消单；退回链专页（顶栏「退回链」）把同一单的原笔与新笔串在一起。未引用单号的普通交评不自动消单。观察员能看退回链，不能发起退回、不能重评。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. taster 对夏茶-C 的不通过行填原因发起退回，顶栏进「退回链」可见 TH-1 待重评，原笔在链上。
5. 提交表单引用 TH-1 再交 9 / 8 / 6，生成新审评行且 TH-1 消单，链上同时出现原笔（4.7 不通过）与新笔（7.9 通过）。
6. 不填单号的普通交评不改变退回单状态。
7. observer 能看退回链专页，但看不到发起退回表单，也不能提交审评。
